# Lifeboat Labs

Free, open-source tools for when something you rely on shuts down. This repository is the website: https://lifeboatlabs.github.io/

## Tools

- **[Done With Publisher](https://lifeboatlabs.github.io/done-with-publisher/)**: open Microsoft Publisher (.pub) files in your browser now that Publisher has stopped working, and get the words, the pictures and a Word file back. [Source code](https://github.com/LifeboatLabs/done-with-publisher)
- **[Save Your Game](https://lifeboatlabs.github.io/save-your-game/)**: when an online game is shutting down, write a free request asking the company for your character and account data before the servers go, and see which games are going offline next. [Source code](https://github.com/LifeboatLabs/save-your-game)
- **[Done With Windows 10](https://lifeboatlabs.github.io/done-with-windows-10/)**: a free, plain-English plan to keep a Windows 10 PC safe without buying a new one, before security updates for home PCs end on October 12, 2027. [Source code](https://github.com/LifeboatLabs/done-with-windows-10)
- **[Done With To Do](https://lifeboatlabs.github.io/done-with-todo/)**: back up your Microsoft To Do lists or move them to Google Tasks before To Do closes on June 30, 2027. [Source code](https://github.com/LifeboatLabs/done-with-todo)
- **[Keep Playing](https://github.com/LifeboatLabs/keep-playing)**: a free server that answers PlayFab calls, so games that used PlayFab can keep working after their servers shut down.
